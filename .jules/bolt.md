## 2026-05-05 - Add React.memo to UserAvatar to prevent AnimatedLeaderboard re-renders
**Learning:** The `AnimatedLeaderboard` component maps list rows inline rather than delegating to a separate `LeaderboardRow` component. As a result, parent state changes (like hover) cause the list to re-render, making the memoization of deeply nested primitive components like `UserAvatar` critical for performance to avoid full-grid re-renders on minor parent state changes.
**Action:** When working on inline list maps (like leaderboards or feeds) that lack dedicated row components, ensure deeply nested primitive components like `UserAvatar` are wrapped in `React.memo()` to prevent full-grid re-renders on minor parent state changes. Also ensure to retain the named function declaration structure (`const Component = memo(function Component(...) { ... })`) instead of converting it to an anonymous arrow function.
