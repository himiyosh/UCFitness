## 2025-02-28 - [Memoizing Deeply Nested Primitives in Lists/Grids]
**Learning:** In highly dense React components like `StepCalendar` (365+ items) or `AnimatedLeaderboard` where inline maps are used without dedicated row components, any state change in the parent (e.g. tooltip hover, long press tracking) causes all deeply nested components to unnecessarily re-render. Omitting `React.memo()` on leaf primitives like `HeatmapCell` or `UserAvatar` incurs massive O(N) render penalties for operations that should be O(1).
**Action:** Always verify if deeply nested list items or grid cells are referentially stable, and aggressively apply `React.memo` to stable leaf components (e.g. `UserAvatar`, `HeatmapCell`) if their parent component has interactive state that triggers full re-renders.
