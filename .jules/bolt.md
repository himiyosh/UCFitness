## 2024-05-07 - [React.memo in Inline List Render Loops]
**Learning:** This codebase heavily utilizes components like `AnimatedLeaderboard` and `FollowingComparison` that map large arrays (like list rows) inline rather than delegating to separate isolated Row components. Because of this architectural pattern, any minor state change in the parent (such as a hover state `isHovered` or a local tab switch) triggers a full re-render of the entire list. Deeply nested primitive UI components—specifically `UserAvatar`—become a significant performance bottleneck as they unnecessarily re-render for every single item in the list.
**Action:** Always verify if functional UI components utilized inside large mapping operations (like lists or grids) are wrapped in `React.memo()`. Retain the named function declaration structure (e.g., `const Component = memo(function Component(...) { ... })`) when adding memoization to ensure React DevTools correctly track the component's original name.
