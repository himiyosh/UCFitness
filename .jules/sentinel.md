## 2025-02-24 - [CRITICAL] Prevent Unhandled Supabase Errors via UUID Validation
**Vulnerability:** The API routes `app/api/user/achievement-progress/route.ts`, `app/api/user/step-calendar/route.ts`, and `app/api/user/follow/status/route.ts` accepted unvalidated `userId` and `targetUserId` query parameters which were then passed directly into Supabase database queries.
**Learning:** Supabase (PostgreSQL) throws unhandled 500 Internal Server Error exceptions if an improperly formatted string is passed into a query expecting a UUID type. This creates an application stability issue and an injection-like vulnerability because raw, untrusted user inputs from query strings are evaluated contextually as a strict database column type.
**Prevention:** Always validate and sanitize user identifiers coming from query parameters (using functions like `isValidUUID` from `@/lib/validation`) BEFORE performing any database query. By returning a 400 Bad Request error early, the application fails securely and prevents database exceptions.
